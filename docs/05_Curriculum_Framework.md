# Best Interests Child Advocate (BICA) Certification Program

## Program Purpose

The **Best Interests Child Advocate (BICA) Certification Program** prepares trained advocates to assess, document, and communicate the best interests of children involved in immigration-related proceedings.

Drawing upon child welfare practice, trauma-informed care, immigration systems knowledge, and interdisciplinary collaboration, the program equips advocates to support child-centered decision-making throughout legal, educational, healthcare, and community settings.

# Capstone Experience

## Best Interests Advocacy Practicum

Participants complete a supervised capstone experience demonstrating mastery of advocacy competencies.

### Required Components

- Case Simulation
- Child Assessment
- Best Interests Evaluation
- Advocacy Report
- Multidisciplinary Case Review
- Final Presentation

---

# Capstone Deliverables

| Deliverable | Description |
|------------|------------|
| Child Assessment | Comprehensive review of child needs |
| Best Interests Analysis | Structured assessment using BICA framework |
| Advocacy Report | Court-style recommendation report |
| Resource Plan | Education, healthcare, and support referrals |
| Presentation | Oral defense of recommendations |

# Certification Outcome

## Certified Best Interests Child Advocate (BICA)

Successful participants are awarded the designation:

> **Certified Best Interests Child Advocate (BICA)**

The certification recognizes specialized preparation in child-centered advocacy for immigration-involved youth and establishes a foundational workforce model for future pilot programs, policy initiatives, grant-funded projects, and interdisciplinary advocacy efforts.

---

# Program Vision

The BICA Certification Program serves as the training foundation for a broader Best Interests Child Advocate Framework designed to strengthen child-centered decision-making within immigration systems.

The long-term vision is to develop a scalable and evidence-informed advocacy model that supports:

- Child safety
- Family stability
- Educational continuity
- Healthcare access
- Trauma-informed practice
- Interagency collaboration
- Long-term child well-being
